# Assistant reminders and alerts

<img src="custom_components/assistant_rules/brand/icon.png" width="128" alt="Assistant reminders and alerts">

Run reminders, timers, sensor alerts, and weather alerts in Home Assistant, with callbacks to Zero.

[![Open in HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=fixtse&repository=ha-assistant-rules&category=integration)

Install through HACS:

1. Open the link above and download the integration.
2. Restart Home Assistant.
3. Add the integration using the button below.

[![Set up integration](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=assistant_rules)

Configure the callback URL and token. Manage reminders and alerts through Zero.

Requires Home Assistant 2026.3 or newer. HACS must already be installed.
